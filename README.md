
# Texas Salary Prediction Project

## Project Overview

This project analyzes Texas government employee salary data and builds machine learning models to predict employee salaries.

---

## Objectives

- Perform Exploratory Data Analysis
- Detect salary outliers
- Analyze wage disparities
- Build salary prediction models
- Compare multiple ML models

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

---

## Best Model

Random Forest Regressor achieved the best performance.

---

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R2 Score

---

## Business Insights

- Top paying agencies identified
- Salary trends analyzed
- Outliers detected
- Wage disparities studied

---

## Conclusion

The project successfully predicts employee salaries and provides useful business insights for payroll management.
